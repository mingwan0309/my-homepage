# 손글씨 폰트 만들기

1. `손글씨_양식지.pdf`(A4 7쪽, 830글자: 숫자·영문·수학기호 + 자주 쓰는 한글 720자)를 **실제 크기 100%**로 인쇄
2. 검은 펜으로 칸마다 글자 쓰기 (회색 점선 = 글자 바닥선)
3. 복사기로 스캔(300dpi 이상, PDF) → Claude에게 전달
4. Claude가 `layout.json` 좌표로 칸을 잘라 글자 모양을 뽑아 `.ttf` 폰트로 만듦
   - 양식에 없는 글자는 기존 손글씨체(Gamja Flower)로 대체

- `make_charset.py` → `charset.json` (글자 목록, 순서 = 양식지 칸 번호)
- `make_template.py` → `손글씨_양식지.pdf` + `layout.json` (레이아웃 바꾸면 스캔 읽는 쪽도 이 값을 그대로 씀)
